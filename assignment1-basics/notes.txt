## The Math Behind Your 45.22M Parameters
With a vocabulary size of 32,000, the structural breakdown of your model is exactly 45.22 million parameters because your setup implements untied weights (two separate matrices for input and output).
Here is how your specific parameters are allocated:

* Embeddings & LM Head (Untied): $2 \times (32,000 \times 512) = \mathbf{32.77\text{M}}$ params.
* Attention Blocks (4 Layers): $4 \times (4 \times 512 \times 512) = \mathbf{4.19\text{M}}$ params (for $W_q, W_k, W_v, W_o$).
* SwiGLU FFN Blocks (4 Layers): $4 \times (3 \times 512 \times 1344) = \mathbf{8.26\text{M}}$ params (for $W_{\text{gate}}, W_{\text{up}}, W_{\text{down}}$).
* Layer/RMS Normalizations: Negligible small bias/gain vectors (~0.01M params).
* Total: 45.22M parameters. [3]

def count_parameters(vocab_size=32000, d_model=512, d_ff=1344, num_layers=4, num_heads=16):
    # Embedding Layer
    # Input embedding: vocab_size * d_model
    # Output projection/LM head shares weight or is separate? Usually distinct unless tied.
    # Let's check untied head first
    embeddings = vocab_size * d_model
    lm_head = vocab_size * d_model
    
    # Per layer components
    # RMSNorm / LayerNorm: 
    # Usually 1 for attn input, 1 for ffn input, 1 for final layer output. 
    # Let's count standard transformer layer:
    # Q, K, V projections: d_model * d_model * 3
    # O projection: d_model * d_model
    # SwiGLU FFN: 
    # Standard SwiGLU has W_gate (d_model * d_ff), W_up (d_model * d_ff), W_down (d_ff * d_model)
    # Total FFN params = 3 * d_model * d_ff
    
    # Normalizations per layer: 2 * d_model (if RMSNorm)
    
    attn_params = (d_model * d_model * 3) + (d_model * d_model)
    ffn_params = 3 * d_model * d_ff
    norms_per_layer = 2 * d_model
    
    layer_params = attn_params + ffn_params + norms_per_layer
    
    # Final norm
    final_norm = d_model
    
    total = embeddings + lm_head + (num_layers * layer_params) + final_norm
    return total

print(f"Untied head total: {count_parameters() / 1e6:.2f}M")
